# 🚀 دليل تشغيل نظام عقاري (Eaqari)

## 📌 نظام التشغيل الكامل بنقرة واحدة

### 🎯 ملفات التشغيل

| الملف | الوظيفة |
|-------|---------|
| `backend/start_all.bat` | **الملف الرئيسي** - اضغط عليه مرتين لتشغيل كل شيء |
| `backend/update_api_url.js` | تحديث رابط API تلقائياً في الواجهة الأمامية |

---

### ⚡ طريقة التشغيل

1. **اضغط مرتين** على ملف `backend/start_all.bat`
2. سيقوم تلقائياً بـ:
   - 🗄️ تشغيل PostgreSQL (قاعدة البيانات المحلية)
   - ⚙️ تشغيل الخادم الخلفي (Backend على المنفذ 5000)
   - 🌐 تشغيل Cloudflare Tunnel (للوصول من أي مكان)
   - 🔄 تحديث رابط API في الواجهة الأمامية تلقائياً

3. ستجد بعدها:
   - الرابط العالمي للخادم في ملف: `backend/tunnel_url.txt`
   - الخادم يعمل محلياً: `http://localhost:5000`
   - لوحة الأدمن: `http://localhost:3000/admin`

---

### 🌍 الرابط الثابت

**ملاحظة هامة:** الرابط من `trycloudflare.com` يتغير كل مرة تقوم فيها بتشغيل النظام.

للحصول على **رابط ثابت لا يتغير**:
1. سجل حساباً مجانياً في: https://dash.cloudflare.com/sign-up
2. أضف نطاقك (مثال: `eaqari.com`)
3. اتبع تعليمات Cloudflare لإنشاء نفق دائم

---

### 🛑 إيقاف النظام

أغلق النوافذ التي فتحتها (Backend, Tunnel, URL Updater) أو أعد تشغيل الجهاز.

---

### ❓ حل المشاكل الشائعة

| المشكلة | الحل |
|---------|------|
| قاعدة البيانات لا تعمل | تأكد من تثبيت PostgreSQL وتشغيله على port 5433 |
| الخادم لا يعمل | شغل `npm run dev` في مجلد `backend` يدوياً |
| الرابط لا يعمل | أعد تشغيل `start_all.bat` |
| الواجهة لا تظهر | شغل `npm run dev` في مجلد `frontend` |
